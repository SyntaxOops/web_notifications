# Changelog

All notable changes to this extension are documented in this file.

## [1.0.0] - 2026-08-16

### Added

- Web Push subscriptions and notification delivery for TYPO3 13.4 LTS and TYPO3 14.3+.
- Backend records for notifications and subscribed devices.
- Delivery status tracking and cleanup of expired subscriptions.
- Page and external URL click targets, with TYPO3 page links routed to absolute site URLs.
- Site Set configuration for the notification icon and image dimensions.
- Console commands for VAPID key generation and notification delivery.
- Root-scoped service worker and frontend subscription endpoint.
- PHP linting, coding-style checks, PHPStan analysis, and a pre-commit hook.
